# 법령·기출·로그인 연결 준비

1주차 준비 목록이다. 승인·다운로드·파싱·모델 적재를 완료했다는 뜻이 아니다. 비밀값은 로컬 .env에 두고 Git·이슈·화면 캡처에 넣지 않는다.

## 법령

[국가법령정보 공동활용 안내](https://open.law.go.kr/LSO/information/guide.do)와 [API 목록](https://open.law.go.kr/LSO/openApi/guideList.do)에서 신청·승인 및 제공 범위를 확인한다.

- [ ] 공동활용 신청/승인 여부, 사용할 법령 검색·본문·연혁 API 확정.
- [ ] API의 OC 인증 식별자·인코딩·응답 형식·호출 제한을 해당 공식 가이드로 확인. 기존 LAW_GO_KR_API_KEY는 자리 표시자이며 임의 값을 추측하지 않는다.
- [ ] 공인중개사법/시행령/시행규칙 범위, 과거 기준일의 시행 버전 확보 방식 확인.
- [ ] 원본 샘플을 확보한 뒤 조/항/호 ID·시행일·출처 URL 파서 검증.
- [ ] sourceVersionKey·원문 hash·수집 시각으로 중복/개정 추적. 공식 원문과 인용용 sourceText를 보존.

키/승인이 없어도 합성 fixture로 저장·검색 구조를 먼저 검사한다. 실제 제공 형식을 확인하기 전 parser 성공으로 보고하지 않는다.

## 기출과 골든셋

[Q-Net 공인중개사 페이지](https://q-net.or.kr/man001.do?gId=08&gSite=L)의 자료실에서 회차별 공개 문제와 최종 정답을 확인한다.

- [ ] 공개 파일·정답·정정 공고·이용 조건을 확인하고 원본 출처/회차/문항/수집일 기록.
- [ ] PDF 추출 결과의 지문·부정형·선지·정답을 사람이 원본과 대조.
- [ ] 복수 정답·정답 미확정·5지선다 외 형식은 격리하여 검수. v1 형태로 억지 변환하지 않음.
- [ ] USER_PROVIDED와 OFFICIAL_VERIFIED 구분; 검수 전 PUBLIC 전환 금지.
- [ ] 골든셋은 별도 평가 정답/근거/기준일 표본. LLM 학습 데이터나 추천용 자동 생성 문제로 간주하지 않음.

## 5주차 로그인 선행 준비

- [ ] 팀의 Google OAuth 프로젝트/담당자·승인된 origin과 callback URI 확정.
- [ ] OAuth client ID/secret은 환경변수로 보관, 외부 identity는 provider/issuer/subject로 식별.
- [ ] 세션 쿠키·CSRF·계정별 라이브러리 통합을 실제 로그인 테스트로 확인.

1주차는 계약까지 준비하며 OAuth 등록이나 인증 기능 구현은 아직 하지 않는다.
